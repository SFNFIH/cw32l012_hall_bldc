# 程序运行结构说明（入门版）

这篇文档讲的是：**烧进 CW32L012 之后，这份固件从头到尾在干什么。**

不要求你先懂磁场定向控制（FOC）。先把它想成「一个很小的电脑，每秒两万次地：看电流、算该怎么拧电机、再改 PWM」。看完你应该能回答：

- 上电后谁先跑、谁后跑
- 按一下键之后电机为什么会转
- 真正驱动电机的代码在哪一个中断里
- 串口那一行 `DBG st=RUN ...` 每个数是什么意思

源码以当前分支为准：无感 **FOC + 高频注入（HFI）**。仓库根目录的 `README.md` 是速查；这里是把「运行结构」摊开讲。

---

## 1. 先用生活比喻建立画面

电机有三个线圈（U / V / W）。单片机不能直接推大电流，它只输出六路开关信号，告诉桥臂「这一相往电源接，还是往地接」。开关得非常快，看起来就像连续的电压。这种开关波形叫 **PWM**。

这份程序做三件互不混淆的事：

| 角色 | 像什么 | 实际在干什么 |
|------|--------|----------------|
| **主循环** `main()` | 前台服务员 | 看按键、看电位器、打印串口。**不**直接改电机波形 |
| **PWM 中断**（每 50 µs 一次） | 后厨，节奏极快 | 采电流、算角度、算电压、写三相占空比 |
| **按键定时器**（每 10 ms） | 门铃消抖 | 只判断 PC13 是不是真的按下去了 |

记住一句话：**电机转不转、转多快，都在 PWM 中断里决定；主循环只负责「开始 / 停止 / 给个目标」。**

---

## 2. 这块板子上有什么

芯片是 **CW32L012C8T6**（ARM Cortex-M0+），程序把它跑在 **8 MHz**。没有浮点运算器，所以正弦、除法、开方能走硬件就走硬件（后面的 CORDIC / EAU）。

### 2.1 和电机有关的脚

| 你在板上看到的 | 单片机脚 | 程序里谁在用 |
|----------------|----------|----------------|
| 相 W 上桥 / 下桥 | PA08 / PB13 | ATIM 通道 1（CH1 / CH1N） |
| 相 V 上桥 / 下桥 | PA09 / PB14 | ATIM 通道 2 |
| 相 U 上桥 / 下桥 | PA10 / PB15 | ATIM 通道 3 |
| 相电流 U / V / W | PA00 / PA01 / PA02 | 三个 INA180，看下桥分流电阻 |
| 调速电位器 | PA07 | 映射成 Iq 目标（转矩给定） |
| 启停键 | PC13 | 按下为高电平 |
| 运行灯 | PB09 | 电机使能时点亮 |
| 调试串口 | PC14 / PC15 | 115200 波特率 |
| 霍尔 PB02 / PB10 / PB11 | 霍尔传感器 | **只显示，不参与控制** |
| 反电势 PA03 / PA04 / PA05、母线 PA06 | 硬件有分压 | **本程序不用**（留给别的分支） |

PCB 丝印对应关系：`PA08 → OUT_W`，`PA09 → OUT_V`，`PA10 → OUT_U`。写占空比时程序已经按这个对调过了，见 `BSP_MOTOR_SetPhaseDuty()`。

### 2.2 为什么要在「PWM 峰值」采电流

三个采样电阻在下桥。中央对齐 PWM 数到最高点再往回减时，三路下桥会同时导通一小段时间，电流从地回来，INA180 才看得见。

所以 FOC **只在计数器刚过峰值时干活**（`BSP_MOTOR_IsPeakUpdate()`）。谷点那个中断来了直接返回，避免采到空窗。

INA180 是 **单向** 放大器：电机电流反向时，芯片看不到负值，会削顶。程序用 `I = 零偏 - ADC` 把「回流变大」译成负电流，但削顶这一物理限制消不掉。

## 3. 源码文件夹怎么分工

上电后真正会执行的，主要是这几层：

```
上电复位
  └─ startup_cw32l012x8.s     复制变量、清零 BSS，跳到 main
       └─ USER/src/main.c     初始化外设，然后死循环当「前台」
            ├─ BSP/*.c        板级：PWM、ADC、按键、FOC 算法
            ├─ USER/src/interrupts_cw32l012.c
            │                 硬件中断的入口，再转给 BSP
            └─ Libraries/     芯片厂家驱动（ATIM、ADC、CORDIC、EAU…）
```

| 文件 | 一句话 |
|------|--------|
| `startup_cw32l012x8.s` | 复位后第一段汇编：`SystemInit` → 拷数据 → `main` |
| `USER/src/system_cw32l012_override.c` | 空的 `SystemInit`，避免去读会 HardFault 的 TRIM 区 |
| `USER/src/main.c` | 时钟、初始化顺序、按键启停、电位器、串口打印 |
| `USER/src/interrupts_cw32l012.c` | `ATIM_IRQHandler` → FOC；`BTIM1` → 按键；霍尔中断 |
| `BSP/BSP_foc.c` | **核心**：状态机 + 电流环 + HFI 估角 + SVPWM |
| `BSP/BSP_motor.c` | 20 kHz 三相互补 PWM，开/关桥臂输出 |
| `BSP/BSP_adc.c` | 临时改通道、软件触发、读一次转换结果 |
| `BSP/BSP_key.c` | 10 ms 扫描 PC13，消抖后记一次按下 |
| `BSP/BSP_halltim.c` | 更新 `g_hall_state`，本固件关掉自动换相 |
| `BSP/BSP_led.c` / `BSP_usart.c` | 灯和 `printf` |
| `Doc/原理图.net` | 原理图网表（不是图画），对脚用 |

看运行结构，建议按这个顺序打开文件：`main.c` → `interrupts_cw32l012.c` 里的 `ATIM_IRQHandler` → `BSP_FOC_PwmIrqHandler`。

## 4. 上电之后：初始化清单

`Reset_Handler` 里做完内存初始化就进 `main()`。`main()` **按固定顺序**打开外设，顺序不能随便调换（PWM 中断要在 FOC 初始化之后才打开）。

```
1. 时钟：内部高速振荡器 HSI ÷ 12 → 8 MHz，PCLK 不分频
2. SysTick：1 ms 节拍（目前主循环基本没用它来定时）
3. LED、串口、霍尔、按键、ADC、电机 PWM
4. 打开 ATIM 更新中断（优先级 0，最高）
5. BSP_FOC_Init()：CORDIC 配成「算 cos/sin」，EAU 开时钟
6. 关一次 ATIM 中断，采一发电位器，再打开中断
       （避免主循环 ADC 和中断里采电流抢同一个 ADC）
7. 电机保持关闭，打印：FOC+HFI | KEY=toggle ...
8. 进入 while(1) 永远循环
```

对应代码：`USER/src/main.c` 的 `main()` 和 `SYSCTRL_Configuration()`。

初始化结束时：

- PWM 定时器已经在数数，但 **主输出 MOE 是关的**，桥臂不发波
- FOC 状态是 `IDLE`
- 霍尔 `BSP_HALLTIM_SetAutoCommutate(0)`：边沿只更新变量，**不会**按霍尔去换相

## 5. 程序同时在跑的四条线

单片机同一时刻只能执行一条指令，但中断会把主循环「暂停一下、干完急事、再回去」。优先级高的可以打断优先级低的。

```
优先级 0（最高）
    ATIM 更新中断 ── 20 kHz，真正的 FOC
    HALLTIM 变化中断 ── 只记霍尔值（本程序不换相）

优先级 2
    BTIM1 ── 每 10 ms 扫一次按键

平时（没有中断时）
    main 的 while(1) ── 电位器、按键事件、串口
```

### 5.1 主循环在干什么（慢、可以打印）

每一圈大约做：

1. **暂时关掉 ATIM 中断**，读 PA07 电位器，再打开中断  
   原因：ADC 同一时间只能采一个通道。中断里要采三相电流，主循环也要用 ADC，必须互斥。
2. 把 0～4095 的 ADC 线性映射成 Iq 目标 `80～900`（`AdcToIq`）。
3. 若按键事件是「按下」：翻转 `motor_on`，调用 `Motor_SetEnable`。
4. 若 FOC 已经变成 `FAULT`：灭灯、打印过流，等待下次按键重试。
5. 电机开着时：Iq 变了就 `BSP_FOC_SetIqRef`；状态变了或转了约 4000 圈主循环，打一行 `DBG`。

主循环 **从不** 调用 `BSP_MOTOR_SetPhaseDuty`。

### 5.2 PWM 中断在干什么（快、不能 printf）

入口：`ATIM_IRQHandler` → `BSP_FOC_PwmIrqHandler`。

中央对齐、重复计数器 RCR=0 时，**峰值和谷点都会进中断**。函数开头：

1. 不是更新标志就退出
2. 状态是 `IDLE` / `FAULT` 就退出（桥臂本来也关着）
3. **不是峰值**（正在上计、刚过谷点）就退出

通过这三关之后，才进入第 7 节那一套 FOC 计算。整个计算必须在几十微秒内结束，所以这里禁止用 `printf`、禁止等很久。

### 5.3 按键中断

`BTIM1_IRQHandler` → `BSP_KEY_TimerIRQHandler` → `BSP_KEY_Scan`。

连续两次（约 20 ms）读到同一电平才算稳定。稳定后从低变高，记下 `KEY_EVT_PRESS`。主循环用 `BSP_KEY_GetEvent()` 取走，取走即清零，所以一次按下只开关一次电机。

### 5.4 霍尔中断

有霍尔的话，`g_hall_state` 会变，串口 `hall=` 能看到。**FOC 的角度 θ 不来自霍尔**，来自对齐 + 开环斜坡 + HFI 锁相环。

## 6. 按一下键：电机状态怎么走

`Motor_SetEnable(1)` 会调用 `BSP_FOC_Start()`：采电流零偏、清积分、把状态设成 `ALIGN`、打开 PWM 主输出。之后全靠中断里的状态机往下走。

```
  按键开
     │
     ▼
  ALIGN  对齐（约 200 ms）
     │   θ 钉在 0，只加 d 轴电压，把转子「拉」到已知位置
     ▼
  IF     电流闭环 + 开环转角（约 1.2 s）
     │   θ 自己往前加；同时注入高频电压，PLL 开始估速
     ▼
  RUN    闭环跑
         θ 改由 PLL 的角速度累加；电位器决定 Iq
         │
         ├─ 电流太大 ──► FAULT（关桥臂，要再按键才能重来）
         └─ 再按键 ────► IDLE（关桥臂，停在原地）
```

| 状态 | 大约时长 | θ（电角度）从哪来 | 电压怎么出 | Iq 目标 |
|------|----------|-------------------|------------|---------|
| `IDLE` | 一直等到按键 | 不用 | 桥臂关闭 | — |
| `ALIGN` | 4000 次 FOC ≈ 200 ms | 强制 0 | 固定 Ud=`ALIGN_V`，Uq=0 | 无电流环 |
| `IF` | 24000 次 ≈ 1.2 s | 每拍加 `s_w_if`（2 慢慢加到 48） | Id/Iq 的 PI + d 轴方波 HFI | 固定 280 |
| `RUN` | 直到停或过流 | 每拍加 `s_omega`（PLL） | 同上，Iq 跟电位器 | 80～900 |
| `FAULT` | 直到再按键 | 不用 | 立即 `BSP_MOTOR_Stop` | — |

`IF` 里角速度从 2 加到 48：电角度是 16 位转一圈（0～65535），48 × 20000 / 65536 ≈ **14.6 Hz 电频率**。电机极对数是 p 的话，轴转速大约是 14.6 / p 转每秒。这是「带着转起来」，好让 HFI 锁相环有速度可跟。

再按键走 `BSP_FOC_Stop()`：状态回到 `IDLE`，关 MOE。过流则进 `FAULT`，主循环把 `motor_on` 清掉，必须再按一次才 `Start`。

## 7. 一个 FOC 周期里发生了什么（最重要）

PWM 频率 20 kHz → 每 **50 µs** 有一次峰值。下面按代码真实顺序写。函数：`BSP_FOC_PwmIrqHandler`。

可以把转子想成指南针。我们不知道它现在指向哪，就在「磁铁方向」（d 轴）上叠一个正负翻转的小电压，看 q 轴电流怎么晃，从而把角度估出来。

### 第 0 步：启动 CORDIC 算 sin/cos

把当前 θ 写成 CORDIC 的 Z 寄存器。芯片自己算，大约 18 个时钟。  
这段时间 CPU 不去空等，立刻去采 ADC。

θ 在程序里是 `uint16`：0 表示 0°，65535 表示快满 360°。CORDIC 的单位是 π，把这个 16 位数当作有符号数写入即可（后半圈会折到负角，和 cos/sin 的周期一致）。

### 第 1 步：采三相电流

对 PA00 / PA01 / PA02 各转换一次：

```
I_phase = 启动时记下的零偏 - 当前 ADC
```

启动时电机还没出力，平均 8 次得到零偏（`CalibOffset`）。

任何一相绝对值超过 `OC_LIM`（1800）→ `FAULT`，后面都不算了。

### 第 2 步：取回 sin、cos

CORDIC 这时多半已经算完。读 X=cos、Y=sin。后面 Park 和反 Park **共用这一对**，不再算第二次。

### 第 3 步：Clarke → Park（三相电流变成 Id、Iq）

- Clarke：U/V/W 合成静止坐标系上的 Iα、Iβ（平面上的两个分量）
- Park：用刚才的 sin/cos 旋到转子上看：
  - **Id**：沿着磁铁，理想情况我们希望它接近 0
  - **Iq**：产生转矩的分量，电位器调的就是它的目标

### 第 4 步：HFI 解调 + PLL（ALIGN 不做）

每个 FOC 周期翻转一次注入极性 `s_hf_sign`（+1 / -1）。注入频率 = 20 kHz / 2 = **10 kHz**。

解调：`符号 × Iq`，再做一个很慢的低通。凸极电机上，这个量近似「角度差」。  
PI（锁相环）把它变成角速度 `s_omega`，`RUN` 时用来推 θ。

ALIGN 阶段转子还在被拉齐，不算 PLL，避免乱估。

### 第 5 步：按状态决定 Ud、Uq

- **ALIGN**：Ud 固定，Uq=0，θ 保持 0。时间到了切 `IF`。
- **IF / RUN**：  
  - Id 目标 = 0，Iq 目标见上表  
  - 两个 PI：电流误差 → Ud、Uq  
  - **然后** 再叠加 `±HFI_V` 到 Ud 上  

注入必须加在电流 PI **之后**。否则 PI 会把你刚注入的电压当扰动抵消掉，HFI 就失效。

### 第 6 步：电压圆限制（EAU）

Ud、Uq 太大时，三相桥会饱和，波形畸变。  
`VoltLimit` 用片上 **EAU**：先开方得到幅值 √(Ud²+Uq²)，再用硬件除法按 `V_LIM / 幅值` 缩回去。  
这比 Cortex-M0+ 的软件除法快很多（开方 17 拍，除法 2～35 拍）。

EAU 全局只有一份，所以 **只在这个中断里用**，主循环不要去抢。

### 第 7 步：反 Park → SVPWM → 写比较寄存器

用同一对 sin/cos 把 Ud、Uq 转回 Uα、Uβ，再变成三相占空比，写入 ATIM。

映射（和 PCB 一致）：

- 相 U → 通道 3（PA10 / PB15）
- 相 V → 通道 2（PA09 / PB14）
- 相 W → 通道 1（PA08 / PB13）

比较寄存器有缓冲，要等下一次更新事件才真正换波形，避免改到一半出现毛刺。

## 8. PWM 波形本身

`BSP_MOTOR_Init` 配置 ATIM：

- 中央对齐，ARR = 199  
  频率 ≈ `8 MHz / (2 × 200) = 20 kHz`
- 三路 PWM1 + 互补输出，`CCER = 0x555`（一直互补，没有「某相浮空」）
- 死区计数 16：约 **2 µs**，防止同一桥臂上下管同时导通
- `Start`：占空比先放到中间，再开 MOE
- `Stop`：关 MOE，并清 CCER，六路都关掉

FOC 不再做传统六步换相。霍尔驱动那套 `Commutate` 已从本分支拿掉。

## 9. 两个数学加速器各管什么

| 外设 | 算什么 | 在程序哪一步 | 为什么不用软件 |
|------|--------|----------------|----------------|
| **CORDIC** | sin、cos | 和 ADC 并行，供 Park / 反 Park | 查表占 Flash，且不能和采样重叠 |
| **EAU** | 32 位开方、有符号除法 | 只在 `VoltLimit` | M0+ 没有除法指令，`/` 会变成很长的库函数 |

**不会**拿 EAU 去替换 `>> 8`、`>> 15` 这种移位——移位更便宜。  
**不会**每拍改 CORDIC 去算向量模长——它已经固定在 cos 模式，模长交给 EAU。

## 10. 串口那一行怎么读

波特率 115200。电机运行中大约每隔一段时间会打印：

```
DBG st=RUN th=80 hall=5 id=12 iq=260 iqref=280 dem=8 w=35
```

| 字段 | 含义 | 怎样算「正常」 |
|------|------|----------------|
| `st` | `ALIGN` / `IF` / `RUN` / `FAULT` / `IDLE` | 启动后应按 ALIGN→IF→RUN 跳 |
| `th` | θ 的高 8 位（0～255 ≈ 0～360° 电角度） | `RUN` 时应该持续增加（或减小） |
| `hall` | 霍尔 3 位状态，仅观察 | 没接霍尔会乱跳或固定，不影响控制 |
| `id` | d 轴电流 | `IF`/`RUN` 时希望靠近 0 |
| `iq` | q 轴电流 | 应跟着 `iqref` |
| `iqref` | 当前 Iq 目标 | `IF` 时约 280，`RUN` 时跟电位器 |
| `dem` | HFI 解调（角度误差的慢变量） | 锁定后应比较小、别大幅乱晃 |
| `w` | PLL 角速度（每拍加到 θ 上的量） | `RUN` 时非零且相对稳定，电机会转 |

上电会先看到：

```
FOC+HFI | KEY=toggle | Iq 80..900 (ADC counts)
```

按键开：`MOTOR ON iq=...`；关：`MOTOR OFF ...`；过流：`MOTOR FAULT overcurrent — press KEY to retry`。

`g_dbg_mbox` 是同一套数的内存镜像（带魔术字），给调试器看，不一定要用。

## 11. 关键参数在哪改

都在 `BSP/BSP_foc.c` 文件顶部的 `#define`。改完需要重新编译烧录。

| 宏 | 默认 | 作用 |
|----|------|------|
| `V_LIM` | 22000 | 电压向量最大半径 |
| `HFI_V` | 1800 | d 轴方波注入幅度；凸极弱就加大 |
| `ALIGN_V` / `ALIGN_TICKS` | 3500 / 4000 | 拉齐力度和 200 ms |
| `IF_TICKS` | 24000 | 开环带转 1.2 s；锁不稳可加长 |
| `IF_W_START` / `IF_W_END` | 2 / 48 | 开环电角速度斜坡 |
| `IQ_IF` | 280 | 开环阶段 Iq |
| `IQ_MAX` | 900 | 电位器上限（`main.c` 里也有一份 80～900） |
| `OC_LIM` | 1800 | 过流阈值（ADC 计数） |
| `HFI_KP` / `HFI_KI` | 6 / 1 | PLL 快慢 |

PWM 频率、死区在 `BSP/BSP_motor.h`：`BSP_MOTOR_PWM_ARR`、`BSP_MOTOR_PWM_DEADTIME`。

## 12. 和「小白」最容易混的几件事

1. **这份程序不是霍尔六步。** 仓库名还带着 `hall_bldc`，是历史名字。当前分支用 FOC + HFI 估角。
2. **电位器不是直接调占空比。** 它调的是 Iq 目标，电流环再去追。
3. **主循环里的 ADC 和中断里的 ADC 是同一个硬件。** 所以主循环读写电位器时必须关 ATIM 中断。
4. **峰值中断才 FOC，谷点中断是空的。** 看到 ATIM 中断频率像 40 kHz 不必慌，一半会马上 return。
5. **反电势脚是接了的，代码没用来换相。** 不要在这份 FOC 里找过零检测。
6. **表贴磁钢凸极很弱时，HFI 可能锁不住。** 表现是 `IF` 结束进了 `RUN`，但 `w` 乱跳、电机发哼不转。先加大 `HFI_V` 或加长 `IF_TICKS`，不是先去改霍尔。
